# LiDAR demo datasets (SYNTHETIC)

Generated by the GeoVision 3D reference project (a friend's project, provided as a ZIP). They are mathematically defined
benchmarks, **not real surveys** and not captured by a drone or LiDAR sensor.

| File | Points | Notes |
|---|---|---|
| synthetic_terrain.las | 41,682 | LAS 1.2, point format 3 (RGB). Flat ground Z=10 m, Gaussian hill peak Z=30 m at (70,70), 10×10×5 m box (class 6). Licence stated in the reference project: CC0 1.0. |
| synthetic_landslide_pre.las / _post.las | 40,401 each | Same slope before/after an excavation and deposit. **No licence is stated in the reference project for this pair**; confirm with its author before public release. |
| *_ground_truth.json | | Expected values written by the generators. The viewer reads these only to show "expected" beside values it measures itself. |

Generator scripts: `sample-data/generate_synthetic_las.py`, `generate_synthetic_landslide.py` in the reference project.
`terrain-preview.jpg` / `landslide-preview.jpg` are screenshots of these datasets rendered in the AERO3D viewer.
The reference docs list the box at (10–20, 20–30); the actual file and its ground-truth JSON have it at (15–25, 15–25), which is what the viewer uses.
Only uncompressed .las is loaded in the browser; the project's .laz files and the UTM variant were not bundled.
